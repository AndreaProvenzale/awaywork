# Implement

The unit is an issue or task with no pull request yet. Implement it on the
branch you are on.

- Read the item and its comments, then the code involved. Ground every
  change in files and functions that exist; reuse what is there.
- When the item is ambiguous, implement the most likely reading and say
  so. When it is too ambiguous to implement, write the questions instead
  of guessing.
- Add or update tests for what you change.

In the PR body: the item linked, what you implemented, the reading you
chose where it was ambiguous, and what you ran to verify.
