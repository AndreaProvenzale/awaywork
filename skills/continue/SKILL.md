# Continue

The unit is a task in progress, with the developer's pull request
linked. Take the next steps, the way the developer would.

- Read the task, the PR description and its diff first. Work out what is
  done, what is left, and which of it is unambiguous.
- Do only the unambiguous next steps, in the style of the existing
  commits. Leave anything that needs a decision for the developer.
- Never undo or rewrite what the developer did.

In the PR body: what you took on and why, what you left and why, and
what you ran to verify.
