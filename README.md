# night-shift

An open-source CLI that spends idle coding-subscription quota overnight on
a developer's leftovers: red CI, review threads, QA feedback, requested
reviews, plans. Runs locally or remotely, on the vendor's own agent CLIs
(Claude Code, Codex, Copilot, Cursor, Gemini, …) with the developer's own
credentials.

Status: **design**. No code yet.
